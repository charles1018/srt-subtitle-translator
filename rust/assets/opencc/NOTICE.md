# OpenCC 字典

本目錄的字典檔（`STPhrases.txt`、`STCharacters.txt`、`TWPhrases.txt`、`TWVariants.txt`）
逐字複製自 Python 套件 `opencc-python-reimplemented` 0.1.7（Python 版 `services/factory.py` 使用的 s2twp 轉換器），
其字典資料源自 [OpenCC](https://github.com/BYVoid/OpenCC)，以 Apache License 2.0 授權。

為了與 Python 版輸出逐字一致，請勿更新為其他版本的 OpenCC 字典；若要更新，需同時更新 Python 相依並重新產生 golden。
